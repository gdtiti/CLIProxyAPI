# 编码约定

## 1. 代码风格

- **格式化：** 使用 `gofmt` 标准格式
- **导入分组：** 标准库 → 第三方 → 项目内部
- **命名：** 遵循 Go 命名惯例（驼峰命名，导出首字母大写）

## 2. 文件组织

```
internal/
├── auth/           # 认证相关（按提供商分子目录）
├── api/            # HTTP API 层
├── config/         # 配置管理
├── runtime/        # 运行时执行器
├── translator/     # 格式转换器
└── util/           # 通用工具函数

sdk/                # 可复用 SDK 组件
cmd/                # 命令行入口
```

## 3. 错误处理

- 使用 `fmt.Errorf("context: %w", err)` 包装错误
- 关键错误记录日志：`log.WithError(err).Error("message")`
- 返回给客户端的错误使用标准 HTTP 状态码

## 4. 日志规范

- **Debug：** 详细调试信息
- **Info：** 正常操作记录
- **Warn：** 可恢复的异常
- **Error：** 需要关注的错误

## 5. 注释规范

- 导出函数必须有文档注释
- 复杂逻辑添加行内注释
- 包级别注释说明包的用途

## 6. 测试规范

- 测试文件命名：`*_test.go`
- 表驱动测试优先
- 关键路径覆盖率 > 80%
