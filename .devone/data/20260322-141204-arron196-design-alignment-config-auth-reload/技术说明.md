## 实际改动摘要

- 本轮改动:
  - 新增环境变量 `CLIPROXY_AUTO_RELOAD_INTERVAL_SECONDS`，通过 `internal/config/config.go` 解析为 watcher 自动重载秒数配置。
  - 在 `internal/watcher` 内新增周期性自动重载循环：每次 tick 先比较 config hash，配置变化时走现有 config reload，未变化时仅重扫认证文件列表。
  - 将认证文件全量缓存重建抽到 `internal/watcher/auth_cache_reload.go`，采用分批并发读取和合成，所有批次完成后一次性替换缓存。
  - 将 `refreshAuthState` 改为优先复用 `fileAuthsByPath`，避免全量 reload 后再次走 `FileSynthesizer` 重扫 `authDir`。
  - 调整 `reloadClients`：在 `forceAuthRefresh=true` 时即使 `rescanAuth=false` 也会重建文件缓存，确保 config 驱动的 synth 变化能落到 file auth 结果。
