- 本轮改动:
  - 为 `auth-maintenance` 新增 `codex-max-request-count` 配置项。
  - 在 management runtime hook 中为文件型 `codex` auth 增加累计请求计数，达到阈值后自动删除文件并禁用运行态 auth。

## Wave 执行记录

### Wave 1

- 目标:
  - 在不改动现有 `401` / `usage_limit_reached` 维护链路的前提下，补一个按累计请求次数删除 `codex` 文件 auth 的配置能力。
- 改动:
  - 配置层新增 `codex-max-request-count`
  - `persistedAuthRuntime` 新增 `request_count`
  - `auth-maintenance` 零值判断补齐 `CodexMaxRequestCount`，避免只配置新字段时被默认配置覆盖
  - hook 对 `codex` 请求结果统一计数，并在达到阈值后走 `removeManagedAuthFile`
  - 新增启用/关闭两类测试
- 结果:
  - 新字段默认关闭，启用后可按累计已完成请求数自动回收 `codex` auth 文件。
  - 仅配置新字段时，运行态配置归一化也能保留该值。
