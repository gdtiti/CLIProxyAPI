## 术语与定义

- `success-rate`：按 provider/model/auth 的时间衰减成功率做调度。
- `simhash`：对请求体做规范化后提取相似度哈希，用于相似请求稳定路由。
- `request blocker`：对已确认会触发 invalid request 的请求体进行短期阻断。
- `request-audit`：异步向外部 endpoint 发送请求/响应审计事件。
- `header 拟真`：将出站请求头调整为更接近目标原生客户端的形态。

## 调研结论

- 结论 1:
  - 最值得先吸收的是反馈式路由体系，而不是 header 细节。
- 结论 2:
  - 第二优先级是 Codex 请求转换性能优化；这一块必须“吸收结构化构造 + cache”，但不能丢掉当前仓库已有兼容补丁。
- 结论 3:
  - request-audit hook 价值明确，属于中优先级可观测性增强。
- 结论 4:
  - Codex header 拟真需要按点吸收，不能整包照搬。
- 结论 5:
  - `429` / quota exceeded 的账号维护语义必须作为主线保护约束固化，否则用户侧配置误差会把本应禁用的账号删掉。
