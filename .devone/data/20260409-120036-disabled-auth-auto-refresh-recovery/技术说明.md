## Wave 执行记录

### Wave 1

- 目标:
  - 把 disabled `codex` auth 自动恢复链落到 maintenance loop，并给恢复过程补 recent buffer + JSONL 审计日志。
- 改动:
  - 新增 auto-recovery metadata helper。
  - 扩展 maintenance candidate scan，允许带系统恢复标记的 disabled auth 进入 `recover` action。
  - 实现 recovery refresh、quota probe、unlock、terminal disable 和 deferred retry。
  - 在 runtime hook 自动禁用链补 marker。
  - 增加 recovery 定向单元测试和 runtime hook marker 断言。
- 结果:
  - 仅系统自动禁用且带 marker 的 disabled `codex` auth 会进入恢复链。
  - access token 过期时会先 refresh，再 probe；额度恢复后自动解锁并清理 marker。
  - quota 未恢复时保持 disabled，并把 `next_check_at` 与 `Quota.NextRecoverAt` 写回运行态/文件。
  - `refresh_token_reused` 与缺失 probe 凭证会进入 terminal disable，并清除 marker，避免无限重试。
  - recovery 事件会进入内存 recent buffer，并追加写入 `auth-maintenance-recovery.jsonl`。
