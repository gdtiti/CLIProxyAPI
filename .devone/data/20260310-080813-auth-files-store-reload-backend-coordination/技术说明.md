## Wave 执行记录

### Wave 1

- 目标:
  修复上传 auth file 未写共享 store，导致 PG 与其它节点保持旧值的问题。
- 改动:
  1. 将 `UploadAuthFile` 的 multipart / raw JSON 两条路径收敛到
     `persistUploadedAuthFile`。
  2. 上传前使用 synthesizer 语义校验 auth JSON，避免把无效 auth file 同步到
     store。
  3. 上传后同步调用当前 store 的 `PersistAuthFiles`，不再只依赖 watcher 异步兜底。
  4. store 持久化失败时恢复上传前文件内容，避免本地镜像目录被错误内容污染。
  5. 成功后再调用 `registerAuthFromFile`，刷新当前节点运行态。
- 结果:
  上传接口现在会把“本地镜像写入、共享 store 持久化、当前节点 reload”收敛为
  同一请求链路内的同步行为。
