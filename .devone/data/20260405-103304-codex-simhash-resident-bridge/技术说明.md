## 实际改动摘要

- 本轮改动:
  - 在 `sdk/cliproxy/auth/conductor.go` 中新增 selector -> manager 的 `BackgroundRefreshHints` / `BackgroundRefreshHintProvider` 抽象。
  - 新增 `finalizeSelectedAuth()` 收口点：manager 在选路完成后持锁应用 resident hint，再返回 selected auth clone。
