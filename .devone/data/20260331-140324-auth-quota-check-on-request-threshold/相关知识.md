## 术语与定义

- quota probe:
  - 指主动请求 Codex usage API `/backend-api/wham/usage`，不是等上游主请求自己返回 quota 错误。
- 请求计数:
  - 指文件型 `codex` auth 的累计已完成请求数，按现有 `RecordCompletedRequest` 语义执行。
