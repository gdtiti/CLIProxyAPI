## 实际改动摘要

- 本轮改动:
  - 为 `sdk/cliproxy/auth` 增加临时禁用 helper，使用 metadata 记录 Codex 429 触发的 5 小时禁用窗口。
  - 修改 `conductor.go`，在 `provider=codex && status=429` 时把整份 auth 置为临时禁用 5 小时，同时统一当前 model 与 global model 的恢复时间。
  - 修改 `selector.go`，把临时禁用中的 auth 视为 cooldown，到期后自动恢复；不会误走永久 `Disabled` 路径。
  - 补充 `selector_test.go` 与 `conductor_quota_integration_test.go` 覆盖 429 触发、禁用期跳过、到期恢复与 snapshot 归一化。
