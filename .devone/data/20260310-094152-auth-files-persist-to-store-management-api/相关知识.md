## 术语与定义

- `authDir`:
  当前节点本地镜像 auth 文件目录。
- `PersistAuthFiles`:
  store 抽象提供的“按文件路径批量把 auth file 写入后端 store”的能力。
- `reload-from-store`:
  把共享 store 的内容拉回当前节点本地目录并刷新当前节点运行态的接口，不负责反
  向推送。

## 调研结论

- 结论 1:
  新接口的最小正确语义应是“当前节点 authDir 落盘文件 -> store”，因为这条链路
  已有完整抽象和实现先例。
- 结论 2:
  若接口不触碰 runtime reload，就不会引入“persist 成功但 reload 失败”的额外
  原子性问题，验证成本也更低。
