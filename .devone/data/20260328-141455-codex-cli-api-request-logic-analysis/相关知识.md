## 术语与定义

- 请求特征: 指请求体结构、头部、会话字段、模型路由、端点切换和缓存行为的组合。
- 保持最新版本信息: 指让模型目录、支持端点、请求头版本指纹与默认 Beta 能力尽量贴近最新上游。

## 调研结论

- 结论 1: 当前链路里“请求语义特征”和“版本指纹特征”是分散管理的；前者主要在 translator/payload，后者主要在 executor/header defaults/model registry。
- 结论 2: 若只想增加可变性，优先动配置；若想改变系统/工具消息映射、WS 增量行为或固定头版本，必须改代码。

## 补充结论：Codex CLI 流式与非流式表象

- 结论 3: 当前项目未发现“同一条已经开始下发 payload 的 Codex 流式请求，会在中途被代理代码主动切成非流式”的逻辑。
- 结论 4: 如果下游表现成“突然不流了”，更可能是后续某一轮请求本来就走了非流式入口，或者是 Responses WebSocket 的本地 prewarm/空完成请求，而不是同一条回答流中途改道。

## 关键证据

- `sdk/api/handlers/openai/openai_responses_handlers.go`
  - `/v1/responses` 只在入口处根据 `stream` 字段选择 `handleStreamingResponse` 或 `handleNonStreamingResponse`。
  - `/v1/responses/compact` 是独立端点，明确拒绝 streaming。
- `internal/runtime/executor/codex_executor.go`
  - `Execute` 会向 Codex 上游发 `stream=true`，但本地会读完整条上游 SSE，直到 `response.completed` 才聚合返回非流式结果。
  - `ExecuteStream` 才会把增量 chunk 逐段转发给下游。
- `sdk/api/handlers/handlers.go`
  - `ExecuteStreamWithAuthManager` 只允许在首个 payload 发出前做 bootstrap retry。
  - 一旦 `sentPayload=true`，后续只会返回流式终止错误，不会改走非流式。
- `internal/translator/codex/openai/responses/codex_openai-responses_response.go`
  - `codex -> openai responses` 的流式翻译器只是透传 `data:` 事件，不做全文缓存聚合。
- `sdk/api/handlers/openai/openai_responses_websocket.go`
  - WebSocket 规范化阶段会把请求统一写成 `stream=true`。
  - 首个 `response.create` 且 `generate=false` 时，会在本地直接合成 `response.created` + `response.completed`，属于 prewarm 短路路径。
- `internal/runtime/executor/codex_websockets_executor.go`
  - WebSocket 握手若返回 `426 Upgrade Required`，只会回退到 HTTP SSE 流式执行，不会回退到非流式。

## 误判来源

- 误判 1: 后续请求体本来就是 `stream=false`，因此入口直接走了非流式 handler。
- 误判 2: 客户端命中了 `/v1/responses/compact`，该端点天然只有非流式。
- 误判 3: Responses WebSocket 首个 `generate=false` 请求只用于 prewarm，表现为瞬时 `created/completed`，容易被误认为“切非流式”。
- 误判 4: WebSocket 上游降级到 HTTP SSE 上游后，仍然是流式，只是传输形态变化会让体感像“变慢或整段返回”。

## 当前证据边界

- 现存仓库日志只能证明服务暴露了 `/v1/responses` 与 `/v1/responses/compact` 路由，不能还原某一轮真实请求体。
- 当前 `config.yaml` 未开启 `request-log`，因此没有足够的现场证据直接判定某一轮是否实际命中了 `stream=false`、`/responses/compact` 或 `generate=false`。
- 本结论属于“静态代码排除 + 已有日志边界说明”，尚未包含真实请求复盘证据。
