## 术语与定义

- 自动链路: 由 runtime result、后台 maintenance、quota probe、请求计数、401 阈值等内部逻辑触发的处置路径。
- 直接删除接口: 当前管理 API 中由外部请求显式触发的删除入口，典型是 `DELETE /v0/management/auth-files`。
- disable: 写 auth 文件 `disabled=true`，并把运行态 auth 标成 disabled。
- delete: 物理删除文件或移入 recycle bin，都会使活动 auth 文件从工作目录消失。

## 调研结论

- 结论 1:
  - 当前“自动删除”并不只存在一处，而是 service maintenance 和 management runtime hook 两条链都还残留删除语义，必须一起收口。
- 结论 2:
  - 用户要的是“保留删接口、禁自动删”，因此正确策略是保留字段名与接口名，只改自动分支的动作类型和文档说明。
